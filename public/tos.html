Diswod

Condiciones del Servicio

Última actualización: 21 de agosto de 2026

Diswod es una aplicación web y una Activity de Discord para lanzar dados de Vampiro: la Mascarada (reglas V20) con amigos. Al usar diswod.keiberup-dev.workers.dev o la Activity dentro de Discord, aceptas estas condiciones.

1. Qué es el servicio

Diswod permite introducir comandos de dados (/r o /roll), ver el resultado en un historial compartido y, si hay asiento libre, en una mesa 3D. No es un producto oficial de Paradox Interactive ni de White Wolf.

2. Uso permitido

  • Uso personal y de mesa de juego con amigos.
  • Máximo 4 asientos en la mesa 3D por sala.
  • No uses la app para acoso, spam, contenido ilegal o para intentar romper el servicio o Discord.

3. Cuentas y Discord

Puedes usar Diswod en el navegador con un nombre que elijas, o dentro de Discord si lanzas la Activity. El acceso a la Activity no publicada puede estar limitado al equipo de desarrollo de la aplicación. Discord tiene sus propias Condiciones; al usar Discord también las aceptas.

4. Contenido que generas

Los nombres, comandos y resultados de dados que envías se muestran a las personas de la misma sala o instancia. No publiques datos personales de terceros. Podemos borrar o limitar el servicio sin aviso si hay abuso.

5. Disponibilidad

El servicio se ofrece “tal cual”, sin garantía de disponibilidad, sincronización perfecta entre jugadores ni de que los dados 3D se vean igual en todos los dispositivos. La sincronización entre clientes usa conexión entre pares (WebRTC) y puede fallar según la red.

6. Propiedad intelectual

El código y la marca Diswod pertenecen a quien opera esta instancia. Vampire: The Masquerade y material relacionado son de sus respectivos titulares. Esta app no incluye el reglamento oficial completo; solo implementa una mecánica de dados.

7. Limitación de responsabilidad

En la medida que permita la ley, no respondemos por daños indirectos, pérdida de partidas, desconexiones o uso que hagas de los resultados de los dados.

8. Cambios

Podemos actualizar estas condiciones. La fecha de arriba indica la versión vigente. Seguir usando Diswod después de un cambio implica aceptar la versión nueva.

9. Contacto

Dudas sobre estas condiciones: el operador de esta instancia (Keiber / keiberup-dev).
